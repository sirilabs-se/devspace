Event platformHi-fi prototype · v05 · neutral tokens
v5What changed in v05
  • One date format: DD MMM YYYY everywhere (09 Oct 2026), joined to time as 09 Oct 2026 · 18:30.
  • 24-hour only: no 12-hour times anywhere, no user setting. Event ranges (18:30–22:30) and doors open/close times are shown.
  • Monday-first calendar with a working keyboard-accessible date picker.
  • No native date or time controls: typed inputs with format hints and matching validation messages, so nothing follows the browser locale.
  • Countdowns use MM:SS (00:42). Relative “Today”/“Yesterday” became real dates.
v4What changed in v04
  • 24-hour time everywhere: event times, lineup, notifications, emails, drafts and audit entries. Time pickers are now true 24-hour inputs (HH:MM) with a suggestions list, so they no longer depend on the browser’s locale.
v3What changed in v03
  • Accessibility engineering: live announcements, labelled dialogs, focus restored after close, one keyboard model for modals, drawers and menus, full tab keyboard support, table roles kept on mobile, skip link.
  • Accessibility matrix screen documents each pattern and what is verified vs still manual.
  • Security wording: the “4 of 4 safeguards” score is gone; MFA now separates primary sign-in, backup second step and last-resort recovery.
  • Discover rhythm: two major destinations (Featured, Trending band) and Near-you map; categories and dates become one quiet utility bar; saved/recent fold into a “For you” tab set.
  • Imagery stress test in the toolbar: bright, busy and dark photo-like textures to check text legibility.
  • Microstates: press feedback, loading buttons on submit, light-on-dark focus rings, larger mobile tap targets.
v2What changed in v02
  • Discover rebuilt as an editorial page: featured hero, category tiles, date strip, trending rail, map + list, personalised rails.
  • Event detail is now a flagship: immersive hero, key-facts strip, who’s going, lineup, gallery, FAQ, similar events.
  • Login & sign-up feel premium; passkey is the primary action, password is the fallback, MFA leads with the passkey.
  • Security Center shows three things; recovery codes, trusted devices and methods live one level down.
  • Organization context bar makes role (authorization) and sign-in rule (authentication) visible everywhere, plus an access-chain diagram.
  • Persona personalities: consumer, organizer, org-admin, security and platform-admin now differ in density and tone.
  • Semantic tokens (success, warning, danger…) documented in the design system.
  • Restrained destructive styling: stripes reserved for irreversible actions.
  • Accessibility: modal focus management and Tab trapping.
