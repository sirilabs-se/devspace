# AudioTube

AudioTube is a Chrome extension that plays YouTube videos audio-only in
the background: it hides the video, forces the lowest available streaming
quality to save bandwidth, and gives you a persistent side panel mini
player — so you can browse other tabs while a video keeps playing as
audio.

## Features

- **Audio-only mode** — one-click toggle (or a keyboard shortcut) hides
  the video, drops it to the lowest streaming quality, and shows a small
  branded overlay in its place. Per tab, not global.
